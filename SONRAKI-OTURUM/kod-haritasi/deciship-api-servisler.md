# Kod haritası — DeciShip API (servisler)

Yollar depo köküne göredir. Giriş, rotalar, şema ve "sık yapılan işler" için: `SONRAKI-OTURUM/kod-haritasi/deciship-api.md`.

## Servisler

Servisler (`Deciship/apps/api/src/services/`):

| Dosya | Ne işe yarar |
|---|---|
| `compare.ts` | Motorun API yüzü: tarifeyi `TariffInput`'a çevirme, `buildContext`/`compareAll`, satır verisi (`resultToLineData`, `parsedToLineData`, `lineRowToParsed`), toplamlar (`computeTotals` + döküm `reconciliation`/`overchargeByType`, `refreshTotals` + `calculatedAt`), yeniden karşılaştırma (`recompareInvoice`, `recompareForTracking`, `computeRecompare`/`previewRecompare`/`applyRecompare`), dayanak: `resolveCurrentBasis`, `loadPricingTariff`, `invoiceBasisState`. |
| `lineWrite.ts` | Satırların toplu ham SQL yazımı (`insertInvoiceLines`, `writeLineResults`, `writeRecalcPending`); sütun listesi elle yazılıdır. |
| `invoiceSerialize.ts` | `serializeLine` (satır yanıtı; notlar burada isteğin diline çevrilir; `reviewCode`, ölçümde `weightMethod`, `photoCount`), `lineInclude`, dayanak görünümü (`calculatedAt`), `serializeImportReport`. |
| `invoicePdfCheck.ts` | PDF fatura satırlarını metinle denetleme (core `checkPdfLines`'in API yüzü), saklanan PDF'in metni, takip no'suz satırların ve sayfa metninin önizleme kaydı (`File.preview`: `pdfPreviewValue`, `readPdfPreview`; bellek kalktı), `PDF_VAT_PCT` (%20 sabit). |
| `evidence.ts` | İtiraz metni ve kanıt ZIP'i aynı satır kümesinden: `loadDisputeDraft`, `renderDisputeText`, `streamEvidenceZip`; sınırlar `EVIDENCE_MAX_PHOTOS`, `EVIDENCE_MAX_BYTES`. KALANLAR 1.12: birim `disputeChargeUnit` (bölen 3000 → desi), imza `signatureContact` (`X-Signature-Email`/`-Phone` başlıkları). Faturanın KDV oranı `invoiceVatPct` (saklanan eşlemeden; PDF'te önizleme kaydının `invoiceVatPct`'i, `invoicePdfCheck.ts` `knownPdfVatPct`); metin core `dispute.ts` `withVat`. |
| `tariffs.ts` | Tarife gövde şeması `tariffBody` (zod), `createTariff`/`replaceTariff`, `serializeTariffFull`, sürüm (`saveTariffVersion`), fiyat sürümü `tariffContentHash`/`ensureTariffRevision`. |
| `tariffImport.ts`, `tariffExcel.ts`, `tariffPdf.ts`, `aiTariffReview.ts` | İçe aktarma taslağı ve uygulama; XLSX şablonu; PDF tarife akışı; yapay zekâ incelemesi. |
| `tariffHealth.ts`, `invoiceHints.ts` | Tarife uyumu raporu; tarife şüphesi. |
| `fx.ts` | **Kur servisi**: TCMB bülteni, önbellek, devre kesici, `prefetch`; testte `setFxService` ile değiştirilir. |
| `reports.ts` | **Raporlar**: fatura Excel (`buildReportXlsx`) ve PDF (`buildReportPdf`, yazı tipleri `assets/fonts`). PDF fark tablosu sınırı `pdfDiffRows` (`REPORT_PDF_MAX_ROWS`, varsayılan 1000; aşılınca en büyük Fark tutarlı satırlar + not `report.pdf.truncatedNote`; toplamlar bütün fatura). Test `test/reportPdfRowLimit.test.ts` (veritabanısız). |
| `disputes.ts` | **İtiraz takibi**: zod gövdeleri, `sendDispute` … `revertDisputeResult`, `listDisputes`, kilit (`lockInvoice`), `disputeFacts` (Merkez de kullanır), satırın aktif itirazda olup olmadığı. |
| `disputes.ts` `sendableLines` | Gönderilecek satır kümesinin tek kaynağı: itiraz metni, kanıt ZIP'i (`evidence.ts` `loadDisputeDraft`), gönderme ve yeniden gönderme aynı satırlar. |
| `disputes.ts` `sendableDigest` | Kümenin anahtarlı özeti (kimlik, takip no, talep kuruşu, para birimi; HMAC); metin ve fatura ayrıntısı verir, gönderme/yeniden gönderme zorunlu alır; tohum/test `currentSelectionDigest`, test `disputeHelpers.ts` `digestOf`. |
| `SELECTION_CHANGED` (itiraz) | `disputes.ts` `assertSameSelection`: fatura kilidi altında özet tutmazsa 409, hiçbir şey yazılmaz; web `SendDialog` metni yeniden aldırır. (Toplu kararın aynı adlı 409'u `bulkDecide.ts`.) |
| `LINE_CHANGED` | `routes/invoices.ts` `PATCH /invoice-lines/:id`: `expectedDecision` kilit altındaki kararla tutmazsa 409; web `LinePanel.tsx` gönderir. |
| `RESULT_LINES_RESENT` | `disputes.ts` `revertDisputeResult`: yerini yeniye bırakmış turdaki girişin satırı sonraki canlı turda yeniden talep edildiyse 409; web `lib/disputes.ts` `revertableResults` aynı kural. |
| `ai.ts`, `aiMapping.ts` | Claude çağrıları: PDF fatura okuma, tartı fotoğrafı; sütun eşleme önerisi. Anahtar yoksa 503 `AI_DISABLED`. `structuredCall`'ı yalnız `aiMeter.ts` çağırır (test kaynakta denetler). |
| `aiMappingMask.ts` | Sütun eşlemede sağlayıcıya giden örnek hücrelerin kişisel veri maskesi : `headerPrivacy` (başlık sınıfı), `shouldMaskSample` (hücre kararı), `maskShape` (A/a/9 biçim maskesi), `headerAliases`/`unaliasHeader` (veri gibi ya da kuşkulu başlık "#<sıra>" takma adıyla gider, yanıtta geri çevrilir); önbellek sürümü `aiMapping.ts` `MAPPING_PROMPT_VERSION`. Kural SPEC §11.2. Test `test/aiMappingMask.test.ts`, istemde gerçek veri yok testi `test/aiMapping.test.ts`. |
| `aiQuotaNotice.ts` | **Hak %80 postası**: `noticeAiQuota` (ücretli çağrıdan sonra `aiMeter.ts` `quotaNoticeAfter`), alıcı `deciship.settings.manage`, tekrar anahtarı `ai-quota-80:<dönem>`, kalıcı işaret `AuditLog` `ai.quotaNotice`, ay dönümünde atlanır; test `test/aiQuotaNotice.test.ts`. Vazgeçme: `AiCallContext.signal` → 409 `AI_CANCELLED`, `cancelledUsage` (üst tahmin, `AI_CANCEL_OUTPUT_TOKENS_PER_SEC`); iş tarafı `jobs/runner.ts` `jobCancelSignal` (yalnız iptal keser; `test/jobCancelSignal.test.ts`). İçe aktarmada sayfa metni silinir: `invoicePdfCheck.ts` `dropPdfPageTexts`. |
| `aiMeter.ts` | **Yapay zekâ sayacı**: `meteredCall` (dakika sınırı, önbellek, tek uçuş, kota, firma yuvası, `AiUsage` satırı), fiyat, dönem, sonuç vermeyen çağrı tavanı ve hatırlama (yalnız ücretli hata; `AiRememberedError`), sayaç sigortası, istek boyu sınırı (413). Sağlayıcının geçici hatası `ai.ts` `AiTransientError` (işte yeniden denenir, `runner.ts` `AI_RETRY_DELAYS_MS`). Kurallar SPEC §5.12, §5.13. Şema `AiUsage`, `AiResultCache`, `AiCreditEntry` (göç `20261113120000_ai_usage`). |
| `onboarding.ts`, `companyData.ts`, `maintenance.ts` | Kurulum durumu; veri sıfırlama ve örnek veri; süresi dolan kayıt temizliği ve yarım kalan yeniden karşılaştırma. |
| `bulkRecalc.ts` | Tarife ya da ayar değişince eski dayanaktaki faturaları toplu geçirme (`previewBulk`, `applyBulk`; iş kancaları `BulkHooks`: ilerleme, kaldığı yer, çit). |
| `jobs/queue.ts` | **Arka plan iş kuyruğu**: `enqueueJob` (tekillik, `joined`), `launchJob`, `kickJob`, `jobView`/`listJobs`/`cancelJob` (`mayCancelJob`), `toJobView`, `cleanupFinishedJobs` (7 gün). |
| `background.ts`, `../worker.ts`, `../startup.ts` | Arka plan işlerinin tek başlatıcısı (iş kuyruğu, ölçüm taraması, bakım) ve kapanışı; `worker.ts` ayrı iş çalıştırıcı girişi (`dist/worker.js`, sağlık dosyası `WORKER_HEALTH_FILE`, SIGTERM; Windows'ta IPC); `startup.ts` iki girişin ortak açılış denetimi. `JOB_RUNNER=off` HTTP'de bakımı da kapatır. | `jobs/handlers/invoiceImport.ts`, `tariffReview.ts`, `jobs/starter.ts` | Büyük CSV/Excel fatura içe aktarma (`routes/invoices.ts` `runInvoiceImport`: satır içi yol ve `INVOICE_IMPORT` işi aynı işlev; denetim kaydı yazımla aynı işlemde, `settled` bayrağıyla yazım sonrası tazeleme; `markCommitted` sonrası durdurma 409) ve tarife incelemesi (`routes/tariffs.ts` `runTariffReview`, işe özgü yapay zekâ önbelleği); `starter.ts` başlatanın etkinlik ve izin denetimi. Silinenlerin kalıcı temizliği (`services/deletedPurge.ts`):

- `purgeDeletedInvoice`: 30 günü dolan silinmiş fatura + satırlar + kaynak dosya; itiraz kaydı olan kalır.
- `purgeMeasurementPhoto`: yalnız silinmiş son sürümün fotoğrafı. Kural tek SQL `photoCandidateSql`: sürüm zinciri, karar, itiraz kanıtı `DisputeLine.measurementId` ve takip no korur.
- `runDeletedPurge` (saatlik bakım): önce fotoğraf adayları, sonra faturalar; imleç `PurgeCursor`; firma listesi `fileCleanup.ts` `maintenanceCompanyIds`, adaylar firma bağlamında, yeni RLS ilkesi yok; disk silme işlemden sonra.
- Kuru çalışma `previewDeletedPurge` (salt okunur işlem) ve komutu `src/cli/purgePreview.ts` (`npm run purge:preview`).
- Süreler `env.ts` `parsePurgeDays` (`DELETED_INVOICE_PURGE_DAYS`, `DELETED_MEASUREMENT_PHOTO_PURGE_DAYS`; varsayılan kapalı, veritabanı saati).
- İtiraz satırına kanıt ölçümünü `disputes.ts` `createRound` yazar (göç `20261123100000_dispute_line_measurement`). Test `deletedPurge.test.ts`.
- Zincir koruması `chainProtectedSql` elle kalıcı silmeyle (`measurementPurge.ts`) ortaktır.
